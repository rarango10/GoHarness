<**State criteria and effect criteria are not tested the same way.** A state one ("on opening, the
last day is selected") is tested with a pure function. An effect one ("on click, the row is
highlighted") needs the code that produces the effect running: if the feature has client-side
JavaScript, declare here **with which test DOM** those criteria are tested in step 5 (in the
`typescript-node` stack, jsdom by default).>

<**"The e2e confirms it" is not an answer** for a criterion that is going to be in a task's
`Covers`: step 7 starts with every task already `done`, and a task doesn't reach `done` without a
`meets` from step 6. If an effect criterion truly can only be tested by navigating, say so here
explicitly —"R9.9: e2e only"—: `planning-tasks` will leave it out of the tasks' `Covers` and record
it as a criterion without a task, verified in step 7.>
